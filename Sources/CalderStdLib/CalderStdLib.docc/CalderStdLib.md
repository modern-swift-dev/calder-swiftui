# ``CalderStdLib``

Swift type helpers used by Calder's UIKit and SwiftUI components.

## Overview

The module contains only shared collection, date, numeric conversion, and string helpers required
by those components. Each helper extends a Swift standard library, Foundation, or Core Foundation
type.
